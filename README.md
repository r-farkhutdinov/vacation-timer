# Vacation Timer

Обратный отсчёт до 14 сентября 2026 года, 16:45.

```bash
npm install
npm run dev
```

Для общего рекорда скопируйте `.env.example` в `.env.local` и заполните:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-publishable-key
```

При деплое GitHub Pages добавьте переменные с теми же именами в настройках Actions.
